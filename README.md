## 🛠️ Getting Started (Windows + npm)

1. Clone the repo:
   git clone https://github.com/eSpark-Consultants/hachem-leadvalidationSaaS-fe.git
   cd hachem-leadvalidationSaaS-fe

2. Install dependencies with npm:
   npm install

3. Start the development server:
   npm run dev   # Visit http://localhost:5173

4. Optional: Run linters / formatters:
   npm run lint  # ESLint
   npm run format  # Prettier check

5. Build a production bundle:
   npm run build  # Output files in /dist
